# Release Notes

## SQL2022EXP-2026Q1

**Release Date:** February 09, 2026

This release includes the following updates:

*   **SQL Server 2022 Cumulative Update 23 (CU23)** (KB5078297)
    *   Build: 16.0.4236.2
    *   [Learn more](https://learn.microsoft.com/en-us/troubleshoot/sql/releases/sqlserver-2022/cumulativeupdate23)
*   **Windows Server 2022 Datacenter**
    *   OS Build: 10.0.20348 (Updated Jan 2026+)
*   **Security Enhancements**
    *   Addressed CVE-2024-55414 (Motorola SM56 Driver).
    *   Addressed CVE-2025-6965 (SQLite/winsqlite3.dll).

### Components Updated

*   SQL Server Database Engine
*   SQL Server Replication
*   Machine Learning Services and Language Extensions
*   SQL Server Management Studio (SSMS) 20.1
